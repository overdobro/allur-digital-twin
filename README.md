# Цифровой двойник завода АЛЛЮР

Виртуальная копия производственной линии автомобильного завода АО «Группа компаний АЛЛЮР» (Костанай), которая работает на данных смен. Линия: **Склад комплектующих → Сварка → Окраска → Сборка → Контроль качества → Склад готовой продукции**.

Система **видит** состояние участков и оборудования против нормативов, **объясняет** причины отклонений и риски с помощью AI и **проверяет решения заранее** — в модели «Что если» и 3D-редакторе, до того как на них потрачены деньги.

**Живая версия:** https://allur-digital-twin.vercel.app
**Подробная документация:** [docs/SYSTEM.md](docs/SYSTEM.md) — модули, формулы, допущения, AI, API, словарь.

---

## Возможности

### Руководитель
- **Обзор завода** — 3D-цех с движущимися кузовами и очередью перед узким местом, KPI (OEE, брак, простой, выпуск) со статусами по нормативам, воспроизведение смен, панель «Требует внимания».
- **Линии и План** — план-факт по линиям; план по моделям (Onix, Cobalt, JAC J7) на смену, день и месяц, прогноз и зоны риска.
- **Качество и Простои** — брак по участкам, журнал простоев, сообщения сотрудников с участков.
- **AI Risk** — риск по каждому участку с факторами из данных, поиск узкого места, рекомендации «что случилось → почему → риск → что сделать».
- **Что если** — «Два будущих» (без действий / с рекомендациями) и песочница с темпом, браком и сменами.
- **3D-редактор** — переставить, добавить, убрать оборудование; проверка столкновений, проходов и свободного места; «было → стало» по выпуску и узкому месту; AI-оценка изменения; сценарии.
- **Идеи и грант** — отбор идей сотрудников и обучающихся: AI-анализ, оценка эксперта, статусы до победителя гранта.

### Сотрудник
Отметка смены, журнал выполненных работ, сообщения о проблемах (сразу видны руководителю), свои идеи.

### Обучающийся
Подать идею и сразу получить AI-анализ и балл → проверить идею на 3D-модели → рейтинг и грант ALLUR IDEA GRANT.

### Режим презентации
Кнопка **«▶ Презентация»** у руководителя: 21 шаг в 5 главах — о системе, завод сейчас, AI и решения, люди и идеи, итог. Каждый шаг сам открывает нужную страницу и подсвечивает блок; ответы AI показываются вживую.

| Клавиша | Действие |
|---|---|
| → / Space / PageDown | дальше (работает с кликером) |
| ← / PageUp | назад |
| F | полный экран |
| Esc | выход |

## Как это работает

```
данные смен ──► расчёт (код) ──► AI (Claude) ──► решение человека
                KPI, OEE, статусы,   объясняет,        руководитель — по заводу,
                узкое место, прогноз  рекомендует       эксперт — по гранту
```

- **Числа считает код, а не AI.** Claude получает уже рассчитанные факты и только формулирует выводы; ответ проверяется по JSON-схеме.
- **Всё вычисленное помечено «расчётный».** Допущения A1–A9 открыты на странице «Допущения и методика».
- **Без ключа Claude система работает так же:** ответы собирают правила (метка «правила · без LLM»), числа не меняются.
- **Статусы — только по порогам** из `backend/app/config.py`, вручную не ставятся.

## Запуск

Нужны Docker и Docker Compose.

```bash
make up        # собрать и запустить → http://localhost:8080
make down      # остановить
make health    # проверить API и режим AI ("llm": true — Claude подключён)
make help      # все команды
```

Вход: экран выбора роли. Руководитель — `manager` / `allur2026`, сотрудники и обучающиеся — демо-аккаунты из списка.
Ключ Claude необязателен: впишите `ANTHROPIC_API_KEY` в `.env` (создаётся из `.env.example`) и выполните `make restart`.

### Разработка без Docker

```bash
make install   # venv для backend + npm ci
make dev       # API :8000 + Vite :5173 (прокси /api)
make test      # pytest + typecheck и vitest фронтенда
make e2e       # сквозной сценарий в браузере против запущенного сайта (нужен pip install playwright)
```

## Деплой на Vercel

Фронтенд отдаётся статикой с CDN, бэкенд FastAPI работает как Vercel Function (`api/index.py` → `backend/app/main.py`), запросы `/api/*` идут в неё (`vercel.json`). Деплой — автоматически при пуше в `main`.

Переменные окружения (Settings → Environment Variables, для Production и Preview):

| Переменная | Обязательна | Зачем |
|---|---|---|
| `DATABASE_URL` | да | Postgres. Проще всего: Storage → **Neon** → Connect to project — переменная появится сама |
| `SECRET_KEY` | да | Подпись cookie входа — длинная случайная строка (`python3 -c "import secrets; print(secrets.token_hex(32))"`). Без неё сервер не пускает в систему, чтобы вход руководителя нельзя было подделать |
| `ANTHROPIC_API_KEY` | нет | Ответы Claude; без него отвечают правила |
| `MANAGER_PASSWORD` | нет | Свой пароль руководителя; если он отличается от демо, подсказка на экране входа скрывается |

Таблицы и демо-данные создаются при первом запросе. Кнопка **«↺ Сбросить демо-данные»** внизу меню руководителя возвращает идеи, сообщения, смены и сценарии к исходным.

### Статическая версия

Тестовые данные фиксированные, поэтому основную часть интерфейса можно отдать без сервера: `make static` выгружает ответы API в JSON и собирает фронтенд в статическом режиме. Роли, идеи и сообщения в статике недоступны. Публикация на GitHub Pages — `.github/workflows/pages.yml` (запуск вручную).

## Архитектура

```
backend/app/data/seed.json ──► repository ──► services/ ──► FastAPI /api/* ──► React (Vite)
                                                  ▲                ▲
                                     Claude API ──┘                └── БД: SQLite локально / Postgres на Vercel
```

| Слой | Технологии |
|---|---|
| Бэкенд | Python 3.12, FastAPI, SQLModel, Anthropic SDK |
| Фронтенд | React 18, TypeScript, Vite, Tailwind, ECharts, framer-motion |
| 3D | three.js, @react-three/fiber, drei, postprocessing |
| Данные | SQLite (локально) или Postgres (`DATABASE_URL`) |
| Инфраструктура | Docker Compose, Vercel, GitHub Actions |

| Папка | Что внутри |
|---|---|
| `backend/app/services/` | расчёты: KPI и OEE, риски и узкое место, прогноз и эффект, план, оценка идей, AI-оценка изменений |
| `backend/app/api/` | маршруты: данные завода, вход и роли, идеи, сообщения, смены, сценарии |
| `backend/app/config.py` | пороги статусов и допущения |
| `frontend/src/pages/` | страницы руководителя; `pages/people/` — сотрудник и обучающийся |
| `frontend/src/components/three/` | 3D-цех и редактор: модель, проверки, идея → 3D |
| `api/index.py` | точка входа Vercel Function |

Полный список API, таблицы БД и формулы — в [docs/SYSTEM.md](docs/SYSTEM.md).

## Тесты

- **pytest** (75) — расчёты KPI и рисков, роли и права, идеи и оценка правилами, сценарии, сброс демо-данных.
- **vitest** (28) — модель «Что если», геометрия и последствия 3D-редактора, идея → 3D; формулы статической версии сверяются с Python.
- **e2e** (`scripts/e2e.py`, Playwright) — вход, все разделы, презентация до конца, консоль без ошибок.

CI (`.github/workflows/ci.yml`) на каждый пуш и pull request: тесты бэкенда; экспорт → типы → vitest → сборка фронтенда; сборка Docker-образов.
